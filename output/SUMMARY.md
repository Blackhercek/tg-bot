# УТРОМ (5 минут, порядок фиксированный)

```
1. Проснулся → туалет
2. Пульс лёжа, 60 секунд, не вставая         → записал
3. Встал на весы (те же, то же место, без одежды) → записал
4. Опросник: сон / усталость / болезненность / стресс, каждый 1–5 → записал
5. Закрыл приложение. НЕ ИНТЕРПРЕТИРОВАЛ.
```

**Обхваты — только Пн, Ср, Пт, Вс.** Не каждый день. Если утром нет времени — **взвешивание всё равно делается**, обхваты пропускаются без последствий.

# В ЗАЛЕ НА ЭТОЙ НЕДЕЛЕ

Тренируешься **как сейчас**, ничего не меняя. Задача — снять числа:

- [ ] **L0 по каждому движению** — вес, на котором достигнут верх диапазона при RIR 2 (8 повторов для базы, 20 для изоляции). Записывать **вместе с оборудованием**: какой блок, какая рукоять, номер плитки.
- [ ] **Пересчитать реальное число рабочих сетов** (RIR ≤3, без разминочных) по каждой группе за неделю. «15–19 на дельту» — оценка, а не измерение, и весь бюджет плана стоит на этом числе.
- [ ] **Выход силой — диагностика.** Вторник: подход до отказа на видео сбоку (X), затем максимум подтягиваний (P). Пятница: брусья (D), вис до отказа (T), 3ПМ подтягивания с весом (W3), три подхода через 180 с (X1/X2/X3).
  **Главное из всего протокола — фаза отказа последнего повтора:** не дотянул до груди / не провернул кисти / не дожал в упоре. От этого ветвится вся дальнейшая работа.
- [ ] **Инвентаризация:** есть ли велотренажёр, машина для махов, шаг гантелей, шаг плиток блока.

# ЧЕГО НЕ ДЕЛАТЬ ЗАВТРА И ВСЮ НЕДЕЛЮ

| Нельзя | Почему |
|---|---|
| Менять программу | Это база сравнения |
| Менять калорийность | Данные пригодны для решений только с дня 12 |
| Делать выводы по весу | Первые 5–10 дней дадут **+1,0…2,0 кг** гликогена, воды и содержимого ЖКТ. Это **не мышцы**: потолок синтеза — 0,15 кг за 10 дней |
| Смотреть график каждый день | Дневная цифра — шум ±0,5 кг. График смотрится **один раз в неделю, в воскресенье** |
| Мерить обхваты ежедневно | Суточное изменение талии ≈ 0,02 см при шуме ±1,4 см. Сигнал/шум 1:30 |
| Оценивать себя в зеркале | На массонаборе зеркало систематически врёт в минус. Особенно после тренировки |
| Вводить новые упражнения | Источник крепатуры станет неотличим |

# ТРИ ФРАЗЫ, КОТОРЫЕ РЕШАЮТ ВСЁ ОСТАЛЬНОЕ

> **1. День закрывается всегда.** Пустая ячейка хуже плохой оценки.
>
> **2. Откат — один приём пищи, а не неделя.** Переел — следующий приём плановый, обычного размера. Не урезаю, не компенсирую.
>
> **3. «Начну с понедельника» — запрещённая фраза.** Понедельника нет. Есть следующий приём пищи.

Прошлые 6 недель провалились не на программе, а на исполнении. Это единственное, что нужно чинить в первую очередь.

# КРИТЕРИЙ, ПО КОТОРОМУ НЕДЕЛЯ 0 СЧИТАЕТСЯ СДАННОЙ

1. Закрыто **≥6 из 7** дней лога питания
2. Есть **≥6 из 7** утренних весов
3. Определена ветка протокола выхода силой
4. L0 измерен минимум по **10 из 14** движений

**Если закрыто меньше 5 дней лога — основной блок не начинается, Неделя 0 повторяется.** Это не наказание. Это единственный дешёвый момент, когда можно узнать, что система учёта не работает, — до того, как на неё три месяца будут опираться решения.

# ЧЕСТНО ПРО РЕЗУЛЬТАТ

**За 30 дней:** +0,45…0,55 кг мышц по всему телу. Это ~1,5 % тощей массы — **в зеркале не видно**. Обхваты +0,3–0,5 см, преимущественно гликоген. Талия в пределах +0,5 см — это **успех, а не отсутствие результата**.

**За 12 недель:** +2,4 кг веса, плечи **+1,5…2,5 см**, талия **+0,6…1,0 см**. Отношение плечи/талия растёт — потому что плечи прибавляют вдвое больше.

**За 90 дней** — первое видимое тканевое изменение.

Продукт первого месяца — не гипертрофия. Это откалиброванная личная калорийность вместо формулы и работающий контур обратной связи. Всё остальное строится на них.
